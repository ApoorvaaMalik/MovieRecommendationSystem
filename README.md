# 🎬 Movie Recommendation System

A **Content-Based Movie Recommendation System** built using **Python, Scikit-learn, Pandas, NLTK, and Streamlit**. The system recommends movies similar to the one selected by the user by analyzing movie metadata such as genres, keywords, cast, crew, and overview.

The project consists of two parts:
- **Content-Based Recommendation Engine** (`content_based_recommender_system.ipynb`)
- **Interactive Streamlit Web Application** (`app.py`)

---

## 📌 Features

- Recommend top 5 movies similar to a selected movie.
- Content-based filtering using movie metadata.
- Interactive and user-friendly Streamlit interface.
- Text preprocessing using stemming.
- Cosine similarity-based recommendation engine.
- Fast recommendations using preprocessed data.

## 📖 Dataset

This project uses the **TMDB 5000 Movie Dataset** available on Kaggle.

The following datasets are used:

- **tmdb_5000_movies.csv**
- **tmdb_5000_credits.csv**

The datasets contain information such as:

- Movie title
- Overview
- Genres
- Keywords
- Cast
- Crew
- Production details

Dataset Source:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

---

## ⚙️ How It Works

1. Load the movie and credits datasets.
2. Merge both datasets using the movie title.
3. Select important features:
   - Overview
   - Genres
   - Keywords
   - Cast
   - Crew (Director)
4. Clean and preprocess the data.
5. Perform stemming using NLTK's Porter Stemmer.
6. Convert text into feature vectors using CountVectorizer.
7. Compute pairwise cosine similarity.
8. Recommend the five most similar movies based on similarity scores.

## 🎯 Recommendation Method

This project uses **Content-Based Filtering**.

Recommendations are generated by comparing movies based on:

- Genres
- Plot Overview
- Keywords
- Cast
- Director

The similarity between movies is computed using **Cosine Similarity** on CountVectorizer-generated text vectors.
